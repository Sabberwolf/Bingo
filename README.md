# BINGO by Sabberwolf

Ziehungsbrett für 90er-Bingo mit Bierzahlen, Gewinnstufen und einer Zuschauer-Anzeige für Fernseher oder Beamer.

## ⬇ Herunterladen

**[BingoSetup.exe – neueste Version](https://github.com/Sabberwolf/Bingo/releases/latest/download/BingoSetup.exe)**

(Alle Versionen: [Releases](https://github.com/Sabberwolf/Bingo/releases))

## Installieren

1. `BingoSetup.exe` herunterladen und doppelklicken – Admin-Rechte sind nicht nötig.
2. Zeigt Windows „Der Computer wurde durch Windows geschützt“: auf **„Weitere Informationen“ → „Trotzdem ausführen“** klicken.
   (Das erscheint bei Programmen ohne kostenpflichtiges Signatur-Zertifikat.)
3. Fertig – „Bingo by Sabberwolf“ liegt im Startmenü und auf Wunsch auf dem Desktop.

## Updates

Das Programm prüft beim Start, ob es eine neuere Version gibt, und bietet das Update an.
Ein Klick genügt – es lädt die neue Version, installiert sie und startet neu. Der Spielstand bleibt erhalten.
